# kaikwanlau.github.io

Source for my personal academic website: **https://kaikwanlau.github.io**

I'm Kai-kwan Lau, an incoming M.Phil student in Mathematics at the Chinese University of Hong Kong, supervised by [Prof. Gary Choi](https://www.math.cuhk.edu.hk/~ptchoi/index.html). My research is in generative AI, geometry processing, and quantitative analysis.

## Repository structure

| Path | Contents |
|------|----------|
| `_pages/about.md` | Homepage — bio, news, publications, honors, education, talks |
| `_pages/art.md` | Digital art / イラスト |
| `_pages/gallery.md` | Photo gallery |
| `_pages/slides.md` | Talk slides |
| `_config.yml` | Site-wide settings |
| `_data/navigation.yml` | Top navigation menu |
| `images/` `files/` | Photos and PDFs |
| `_layouts/` `_includes/` `_sass/` `assets/` | Theme internals — rarely edited |

## Making changes

Edit the Markdown in `_pages/`, commit, and push. GitHub Pages rebuilds the site automatically within a minute or two.

Images are resized to a maximum of 1600px on the long edge before committing, since nothing on the site displays wider than 768px.
